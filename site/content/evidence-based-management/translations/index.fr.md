Scrum.org publie ce guide dans plus de vingt langues. Aucune n'est hébergée ici, car aucune
licence le permettant n'est indiquée pour aucune version, dans aucune langue.

La version de 2024 est publiée en anglais et dans une vingtaine d'autres langues.
L'azerbaïdjanais, le biélorusse, le persan, le russe et le turc restent sur la version de
2020 : la langue choisie détermine donc la version obtenue.

Le répertoire des éditeurs, avec le sélecteur de langue, se trouve sur
[scrum.org](https://www.scrum.org/resources/evidence-based-management-guide).
