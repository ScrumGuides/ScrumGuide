El text principal d'aquesta guia és la Guia Scrum del novembre del 2020, de manera que les seves
traduccions són les traduccions d'aquell document: les han fet els traductors que Ken Schwaber i
Jeff Sutherland anomenen per a cada llengua. Cadascuna porta la mateixa declaració de Creative
Commons Reconeixement - CompartirIgual 4.0 que el document anglès.

Per a les llengües marcades com només PDF, el document traduït és aquí, però el text principal no
té edició web. Si trobeu un error en una traducció, feu-ho saber a aquell traductor o a l'editor.

El catàleg de l'editor és a [scrumguides.org](https://scrumguides.org/).
