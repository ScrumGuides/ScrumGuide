The text of this guide is the November 2020 Scrum Guide, so its translations are the
translations of that document: the work of the translators credited against each language by
Ken Schwaber and Jeff Sutherland. Every one of them carries the same Creative Commons
Attribution ShareAlike 4.0 notice as the English document.

A language listed as PDF only has its translated document here but not its text as a page.
If you find an error in a translation, raise it with that translator or with the publishers.

The publishers' own directory is at [scrumguides.org](https://scrumguides.org/).
