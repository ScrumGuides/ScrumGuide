guide_whatis: |
  **Если прочитать только одно — прочитайте это.** Начните отсюда, а затем прочитайте
  Руководство по Scrum.

  Руководство по внедрению — и то, с которого стоит начать. Руководство по Scrum 2026
  устанавливает, чего должен достигать каждый элемент Scrum, и намеренно ничего не говорит о
  том, как. Это руководство — про «как»: ограничения по времени, размер команды, порядок каждой
  встречи, техники, которые команда действительно применяет. Две команды могут обе правильно
  работать по Scrum и расходиться на каждой странице этого руководства. По Руководству по Scrum
  не может расходиться ни одна из них.

  Его текст — Руководство по Scrum от ноября 2020 года Кена Швабера и Джеффа Сазерленда,
  воспроизведённое по лицензии CC BY-SA 4.0. Эта версия — наиболее широко преподаваемое
  описание Scrum на практике, поэтому это лучшая отправная точка, какая может быть у команды.
  Этот сайт публикуют не они, а канонический источник —
  [scrumguides.org](https://scrumguides.org/).

  **Лицензия: CC BY-SA 4.0.** Полный текст — на странице версии, с собственным уведомлением
  документа внизу.

  Руководства по внедрению добавляют указания для конкретного контекста. Они могут дополнять
  условия исходного руководства и сужать их далее. Они не могут их отменять или ослаблять.
