# Licence review — every guide edition on this site

This file is the evidence for a publishing decision. Specification §9.1 makes the licence on
each individual edition a blocking condition. No edition's text goes on this site until the
copyright and licence notice printed **in that edition's own document** has been read and
recorded here. A licence found on one edition is never assumed to run backwards to an earlier
one — in all three guides reviewed so far, the earliest editions reserve all rights and the
later ones do not.

Reviewed 19 November 2026. Three guides: the Scrum Guide, the Kanban Guide for Scrum Teams,
and the Nexus Guide.

## Summary across all three guides

Every published version of every guide has a page on this site. Where the licence allows it,
that page carries the edition's full text. Where it does not, the page presents the edition —
what it is, where it sits in the lineage, the notice it carries — and links the publishers'
own document instead of re-hosting it.

| Guide | Text reproduced | Presented, text not reproduced |
|---|---|---|
| The Scrum Guide | 2013.7, 2016.7, 2017.11, 2020.11 | 2009.11, 2010.2, 2011.7, 2011.10 |
| Kanban Guide for Scrum Teams | 2018.2, 2018.4, 2019.9, 2021.1 | none |
| The Nexus Guide | 2018.1, 2021.1 | 2015.8 |

In all three guides the split falls at the same place: the earliest editions reserve all
rights, and from one release onward the publishers moved to Creative Commons Attribution
ShareAlike 4.0 and have stayed there.

## How the text was transcribed

Each published edition was converted from the publishers' own file. Nothing was summarised,
modernised, corrected, reordered or added to the guide text.

- **2013.7, 2016.7, 2017.11** — from the PDF. Headings, paragraph boundaries, list structure and
  inline emphasis were taken from the document's own typesetting (heading styles at 24pt, 21pt
  and 18pt; body at 17pt), and the resulting markdown was then compared character for character
  against an independent text extraction of the same PDF. The only differences are list markers,
  which markdown writes as syntax, and hyphens restored in `self-organizing`, `time-box`,
  `burn-downs` and `one-month`, which the document breaks across lines and the extractor drops.
- **2020.11** — from the HTML edition the publishers serve at scrumguides.org, which already
  carries the document's heading hierarchy, and verified the same way against the PDF.

Three transcription decisions, applied to every edition of every guide on this site. The
examples are from the Scrum Guide; the Kanban and Nexus pages follow the same three rules:

1. **Heading depth, not point size.** Each document's top-level sections become `##`, their
   subsections `###`, and sub-subsections `####`. In 2013, 2016 and 2017 the authors styled some
   second-level sections (Transparency, Inspection, Adaptation) with the third-level heading
   style, skipping a level. Those are rendered at their nesting depth rather than their point
   size, so the table of contents and the anchor links have no gap in them. The publishers' own
   2020 HTML does the same thing with the same headings.
2. **The title block is not repeated in the body.** Each document opens with its title,
   subtitle, date and byline. The title and date are already in the page's front matter, so the
   body opens with the subtitle, date and byline in a short notice, then the first section.
3. **Two things in the publishers' files are not guide text and are not carried.** The running
   page footer, which repeats the copyright notice on every page — that notice appears once, at
   the foot of the body, where the document also prints it in full. And, on the 2020 page, the
   line scrumguides.org adds to its HTML saying that the HTML is a port of the PDF, plus the
   "Ken Schwaber & Jeff Sutherland November 2020" signature that the PDF prints after the
   Purpose section and the publishers' own HTML omits.

## Two editions this review added to the lineage

The site's original edition set (specification §5.3) listed six editions, running 2010.2 →
2011.10 → 2013.7 → 2016.7 → 2017.11 → 2020.11. This review found two more published documents

1. **`2011.7`, July 2011.** Named as a release in its own right by the publishers' own revision

# Method, and what applies to all three guides

## What an edition page carries when the text cannot be reproduced

Five editions reserve all rights. Each still has a full page, because the lineage this site
presents is not honest with gaps in it. Those pages carry:

- the edition's own cover title, subtitle, date and byline;
- what the edition is and where it sits in the lineage, drawn from the publishers' own revision
  histories and attributed to them, with any quotation short;
- a link to the publishers' own file, so a reader can go and read the edition;
- the copyright notice the document carries, quoted as a fact about the edition, and a line
  saying the document it governs is not reproduced here.

What those pages do not carry is the guide's text, in whole or in part.

## Share-alike

CC BY-SA 4.0 requires that an adapted version be licensed on the same terms. The published
pages are reproductions, not adaptations: the text is unaltered and each page carries its
document's own copyright notice, the authors or publisher, and a link to the canonical source.
Nothing on those pages is offered under terms more restrictive than CC BY-SA 4.0.

## Verification

Every published body was converted from the publishers' own file and then compared character
for character against an independent text extraction of that same file. The only accepted
differences are list markers, which markdown writes as syntax, and hyphens restored in words
the document breaks across a line — `self-organizing`, `self-manage`, `time-box`,
`burn-downs`, `one-month`, `work-in-progress` — which the extractor drops.

Each document was also scanned for large vertical gaps between text lines, to catch content a
text extraction cannot see. That scan found the two Nexus framework diagrams and, in the
September 2019 and January 2021 Kanban guides, Little's Law, which those documents typeset as
a fraction:

> *average cycle time = average work in progress / average throughput*

It is rendered on those two pages as a single line with a solidus, because this site has no
mathematical typesetting. No other guide edition contains a figure, formula or table.

## When to revisit

- If a publisher re-publishes the February 2010 Scrum Guide, the October 2011 Scrum Guide or
  the August 2015 Nexus Guide under Creative Commons, that edition can be published here.
  Nothing short of a licence grant from the rightsholders changes those three findings.
- If the file scrumguides.org serves for the July 2013 Scrum Guide changes its notice again,
  re-read §1's 2013.7 entry before changing that page.
- Scrum.org serves the Kanban and Nexus files from a file store whose paths are not advertised
  as stable. If a source link above dies, the file is still identifiable by its SHA-256.
