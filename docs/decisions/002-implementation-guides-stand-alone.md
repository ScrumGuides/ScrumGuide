# 002 — Implementation guides stand alone

Date: 2026-11-26

## Context

The AI Guide for Scrum Teams implements Scrum Guide 2026. A reader may read only the
implementation guide. Decision 001 says guides inheriting from `2026.1` follow their parent's
agreed wording.

## Decision

An implementation guide stands alone. It defines every term it uses, so it can be read without
Scrum Guide 2026.

An implementation guide uses a Scrum Guide 2026 term only where it means the same thing. Where
its meaning differs, the implementation guide uses its own term.

An implementation guide may add to Scrum Guide 2026 and may constrain it further. It may not
contradict it.

An implementation guide follows the style in `docs/style.md`.

## Consequences

Reconciling an implementation guide against Scrum Guide 2026 checks for contradictions, and for
shared terms used with a different meaning. It does not copy Scrum Guide 2026 wording.

This narrows the last paragraph of 001. An implementation guide follows its parent's agreed
wording only where it restates one of its parent's rules.

## Status

Accepted. Standing.
